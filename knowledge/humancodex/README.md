# Immutable HumanCodex (canon home)

- `HUMANCODEX-CORE.md` is the **active rulebook** for the Next-Xus Federation's running agents: Catalyst and Pontus (`Keywebco/nextxus-sim-api`) and Roger Sim (`Keywebco/roger-sim-api`). Both services fetch it from this repo at startup over raw GitHub and keep a bundled copy as a fallback.
- **Source:** "Full Immutable HumanCodex NextXus**MD", Google Doc by Roger Keyserling and AI, version dated 2026-09-06 (doc id `1GwX_k8HfgRAq0qVsQlrYNoLDiviq9VvIsK_cbkAXzwU`). The Drive document stays the authority and is never edited from here.
- **Why the full text is not committed here:** the source document links to 14 of Roger's other Google Drive documents by their sharing URLs. Publishing those in a public repo could expose private material, so only the condensed core is filed until Roger decides. The full export (about 512K characters; the document body appears twice in a row, nearly identical) is kept off-repo.
- **Directive count:** the Codex says there are 73 Sacred Directives but names only 22 by number, plus DIR-000. The core lists all 73 from the ratified Cathedral Edition v1.1 and marks which ones the Codex names.
- **Supersedes:** nothing. No earlier codex file existed in this repo. Per the No Delete policy, future revisions go in as new dated versions, and older ones move to an `archive/` folder. Nothing gets deleted.
- **Federation stack:** GitHub, Google Drive, the Federation repositories, and the Immutable HumanCodex.
